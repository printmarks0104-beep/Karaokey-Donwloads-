# Original 47,997 VKPK integrity audit

The read-only workflow fetches the requirements-v1 private release and streams the entire original 496,506,044-byte archive, confirming pinned SHA-256, header CRC, declared 47,997 count and index bounds. No songs, lyrics, keys or secret-bearing assets are exported.

Passing this job **does not mean** that 47,997 records are decoded, playable, licensed or verified on Android. The existing SING'OKEY RealPackCheck can validate six sample records only with an authorized publisher credential. Every-record validation and actual Android playback remain separate gates. No changes to SING'OKEY APK, PR #33, payment config or signing credentials.
